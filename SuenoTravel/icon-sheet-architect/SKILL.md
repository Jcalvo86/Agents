# Skill: Icon Sheet Architect

## Propósito
Generar prompts para producir hojas de recursos (*asset sheets*) con ilustraciones arquitectónicas de monumentos específicos. Los iconos resultantes deben compartir la estética de tinta/sepia vintage pero estar aislados sobre fondo negro puro para permitir transparencia directa o fácil remoción de fondo.

## Reglas de Composición Visual
1. **Aislamiento para Transparencia:** Fondo negro puro absoluto (`isolated on a solid pitch-black background`) para permitir transparencia inmediata vía modo de fusión (Screen / Trama) o recorte por contraste.
2. **Estilo Gráfico:** Ilustración pictórica a tinta fina (*fine-ink hand-drawn*) con detalles, sombras y textura sepia/beige cálido.
3. **Distribución:** Hoja de recursos organizada (*grid layout with neat spacing*) con espacio suficiente entre cada ilustración.
4. **Coherencia:** Estilo retro-vintage editorial compatible con los mapas base.

## Plantilla del Prompt (Inglés - Principal)
```text
An isolated asset sheet of fine-ink hand-drawn architectural landmark icons for [PAÍS / REGIÓN]. Includes detailed pictorial vector-style illustrations of [LISTA DE MONUMENTOS EN INGLÉS]. Hand-drawn ink line art with soft warm beige sepia shading and subtle vintage paper texture accents. Completely isolated on a solid pitch-black background, vector sheet grid arrangement with neat spacing between icons, clean graphic design style matching vintage editorial cartography --ar 4:3
```
